Rahul Pal - Full Stack Developer Portfolio

This repository contains a full-stack portfolio project built with the MERN stack.

Folders:
- `frontend/` - React + Vite + Tailwind UI
- `backend/` - Express API, MongoDB, authentication, file uploads

Setup:
1. Copy `backend/.env.example` to `backend/.env` and fill your real values.
2. Install dependencies in both `frontend/` and `backend/`.
3. Run the backend on port `5000`.
4. Run the frontend on port `5173`.

Never commit real `.env` files or secrets to GitHub.
